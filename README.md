# Diabetic Retinopathy Prediction
This project predicts the likelihood of diabetic retinopathy using patient health data (tabular features such as age, blood sugar, blood pressure, cholesterol, etc.). It applies machine learning techniques to assist in early detection of this serious eye condition.
## Motivation
Diabetic retinopathy is a leading cause of blindness worldwide. Early detection can prevent severe outcomes. This project demonstrates how data science and machine learning can support healthcare by predicting risk levels based on patient data.
## Dataset
- Patient health records (structured/tabular data).
- Features used: Age, Blood Sugar, Blood Pressure, Cholesterol, etc.
- ## Model
- Random Forest Classifier
- Data preprocessing with scaling
- Evaluation metrics: Accuracy, Confusion Matrix, ROC Curve
